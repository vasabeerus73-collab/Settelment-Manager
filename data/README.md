# Settlement Manager data

Эта папка содержит контент модуля, а не прогресс мира.

- `manifest.json` указывает, какие data-файлы загружать.
- `resources.json` описывает типы ресурсов.
- `default-state.json` используется только как начальное состояние нового мира и как источник недостающих полей при миграции.
- `buildings/index.json` перечисляет JSON-файлы зданий.
- каждый файл в `buildings/` описывает одно здание.

Прогресс мира (количество ресурсов, построенные здания, доступ по чертежам, просьбы, проекты и летопись) по-прежнему хранится в Foundry world setting.

Важно: ID здания после начала кампании лучше не менять. Именно по ID сохранённое состояние связывается с определением здания.
